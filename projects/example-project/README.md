# Example project

This folder is a template. Copy it to `projects/<your-explainer>/` and fill it in. One folder per explainer holds everything you decide before the film is built.

- `README.md` (this file): who the film is for, what they should know or do afterwards, and how long it should run.
- `research.md`: the facts, sources and quotes the script may rely on.
- `script.md`: the narration, one row per spoken line.
